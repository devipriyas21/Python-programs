PYTHON LOOPS
============

Loops are used to execute a block of code repeatedly.

Python mainly has two types of loops:

1. for loop
2. while loop


--------------------------------------------------
1. FOR LOOP
--------------------------------------------------

A for loop is used to iterate over a sequence such as a list,
tuple, string, range, etc.

Syntax:

for variable in sequence:
    # code to execute


Example:

for i in range(5):
    print(i)

Output:
0
1
2
3
4


Example with a list:

fruits = ["Apple", "Banana", "Mango"]

for fruit in fruits:
    print(fruit)


Example with a string:

name = "Python"

for character in name:
    print(character)


--------------------------------------------------
2. RANGE() FUNCTION
--------------------------------------------------

The range() function generates a sequence of numbers.

Syntax:

range(start, stop, step)

Note:
The stop value is not included.

Example:

for i in range(1, 6):
    print(i)

Output:
1
2
3
4
5


Example with step:

for i in range(0, 10, 2):
    print(i)

Output:
0
2
4
6
8


Reverse loop:

for i in range(5, 0, -1):
    print(i)

Output:
5
4
3
2
1


--------------------------------------------------
3. WHILE LOOP
--------------------------------------------------

A while loop repeatedly executes a block of code as long
as the given condition is True.

Syntax:

while condition:
    # code to execute


Example:

i = 1

while i <= 5:
    print(i)
    i += 1

Output:
1
2
3
4
5


Example:

count = 5

while count > 0:
    print(count)
    count -= 1


--------------------------------------------------
4. BREAK STATEMENT
--------------------------------------------------

The break statement is used to immediately terminate a loop.

Example:

for i in range(1, 10):
    if i == 5:
        break
    print(i)

Output:
1
2
3
4


Example with while loop:

i = 1

while i <= 10:
    if i == 6:
        break
    print(i)
    i += 1


--------------------------------------------------
5. CONTINUE STATEMENT
--------------------------------------------------

The continue statement skips the current iteration and
moves to the next iteration of the loop.

Example:

for i in range(1, 6):
    if i == 3:
        continue
    print(i)

Output:
1
2
4
5


Example:

for i in range(1, 11):
    if i % 2 == 0:
        continue
    print(i)

Output:
1
3
5
7
9


--------------------------------------------------
6. PASS STATEMENT
--------------------------------------------------

The pass statement does nothing.

It is used as a placeholder when a statement is required
but no action needs to be performed.

Example:

for i in range(5):
    pass


Example:

for i in range(1, 6):
    if i == 3:
        pass
    else:
        print(i)


--------------------------------------------------
7. ELSE WITH LOOPS
--------------------------------------------------

Python allows an else block with for and while loops.

The else block executes when the loop finishes normally
without encountering a break statement.


Example:

for i in range(5):
    print(i)
else:
    print("Loop completed")

Output:
0
1
2
3
4
Loop completed


Example with break:

for i in range(5):
    if i == 3:
        break
    print(i)
else:
    print("Loop completed")

Output:
0
1
2

The else block does not execute because the loop was
terminated using break.


--------------------------------------------------
8. NESTED LOOPS
--------------------------------------------------

A loop inside another loop is called a nested loop.

Example:

for i in range(3):
    for j in range(3):
        print(i, j)


Example:

for i in range(1, 4):
    for j in range(1, 4):
        print("*", end=" ")
    print()

Output:
* * *
* * *
* * *


--------------------------------------------------
9. LOOPING THROUGH A DICTIONARY
--------------------------------------------------

Example:

student = {
    "name": "Rahul",
    "age": 20,
    "course": "CSE"
}

for key in student:
    print(key)


To print keys and values:

for key, value in student.items():
    print(key, value)


--------------------------------------------------
10. LOOPING THROUGH A LIST USING INDEX
--------------------------------------------------

Example:

fruits = ["Apple", "Banana", "Mango"]

for i in range(len(fruits)):
    print(i, fruits[i])

Output:
0 Apple
1 Banana
2 Mango


--------------------------------------------------
11. ENUMERATE()
--------------------------------------------------

The enumerate() function gives both the index and value.

Example:

fruits = ["Apple", "Banana", "Mango"]

for index, fruit in enumerate(fruits):
    print(index, fruit)

Output:
0 Apple
1 Banana
2 Mango


--------------------------------------------------
12. COMMON LOOP PROGRAMS
--------------------------------------------------

Program to print numbers from 1 to 10:

for i in range(1, 11):
    print(i)


Program to print even numbers:

for i in range(1, 11):
    if i % 2 == 0:
        print(i)


Program to print odd numbers:

for i in range(1, 11):
    if i % 2 != 0:
        print(i)


Program to find the sum of numbers from 1 to 10:

total = 0

for i in range(1, 11):
    total += i

print(total)


Program to print multiplication table:

n = 5

for i in range(1, 11):
    print(n, "x", i, "=", n * i)


Program to find factorial:

n = 5
factorial = 1

for i in range(1, n + 1):
    factorial *= i

print(factorial)


Program to reverse a number:

n = 12345
reverse = 0

while n > 0:
    digit = n % 10
    reverse = reverse * 10 + digit
    n //= 10

print(reverse)


--------------------------------------------------
13. IMPORTANT DIFFERENCE
--------------------------------------------------

FOR LOOP:
- Used when the number of iterations is known.
- Commonly used with range(), lists, strings, tuples, etc.

WHILE LOOP:
- Used when the number of iterations may not be known.
- Continues as long as a condition is True.


Example:

for i in range(5):
    print(i)


i = 0

while i < 5:
    print(i)
    i += 1


--------------------------------------------------
14. IMPORTANT KEYWORDS
--------------------------------------------------

break
    Terminates the loop completely.

continue
    Skips the current iteration.

pass
    Does nothing and acts as a placeholder.

else
    Executes when a loop completes normally.
